# lightcraft-classic (Vibeclones mirror)

Hosted copies of the browser (WebAssembly) builds of [LightCraft Classic](https://github.com/emmertex/lightcraft-classic), by emmertex. The newest version lives at playground.daijro.dev/lightcraft-classic; this repo keeps older versions open-able so the timeline can be explored in a browser. This repo only mirrors upstream release zips; the code is theirs. Upstream license: MIT AND Apache-2.0.

- Latest: `/lightcraft-classic/latest/`
- Specific version: `/lightcraft-classic/v<version>/`
- Version list: `/lightcraft-classic/versions.json`

Each version folder is the unmodified contents of upstream's browser build zip from the matching release. A scheduled workflow mirrors new releases.
